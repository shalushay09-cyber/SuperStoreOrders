# SuperStoreOrders
The analysis of the SuperStoreOrders dataset based on two programming languages: SQL and Python. Made without a visualisation and Power BI because the target of this analysis is to practice programming in two languages, understanding the structure to write queries in the language that is more convenient in the future. I wanted to write 200+ queries in both languages, but at the 169th query I got very bored writing in both and decided to finish this dataset, because I understood the logic and structure in Python more or less.
